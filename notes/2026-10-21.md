
## Brickbreaker Prompt

The core logic of the game should be cljc. So that we can in the future simulate the game without a UI. The state of the game should be in a single atom. Actions take by the user should be well-defined so that we can do: game-state + action => next-game-state

A UI should be create with shadow-cljs + reagent.

Features we expect of the game:
  one paddle, moves horizontally at bottom, at some speed when user provides input

  brick area:
    10x10 randomly filled in

Sketch out the state.
